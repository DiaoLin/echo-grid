# EchoGrid（校园噪声地图）

基于 ESP32 与网页可视化的校园噪声采集、展示与热力图研究设计。

> 华南师大附中第一届科技创新研究设计大赛 · 信息技术与工程方向  
> 队伍：高一（10）班 陈瀚
> 状态：研究设计阶段（2026.11—2026.12）

---

## 1. 项目简介

EchoGrid 用 ESP32 + 数字麦克风在校园不同测点采集噪声分贝，通过本地 Web 接口或 WiFi 上传，在网页上实时显示分贝值、历史曲线和校园平面图噪声热力图，并支持按课间 / 午休 / 放学分时段对比，为校园噪声治理提供低成本、可视化的数据支持。

**当前阶段目标：** 完成《研究设计》，并跑通“ESP32 采集 → 网页显示”的最小链路。  
**后续阶段目标：** 科技节前完善多测点采集、校园热力图和分时段对比。

## 2. 系统架构

```
INMP441 麦克风
      │ I2S
      ▼
   ESP32
   ├─ 计算平均分贝 / Leq
   ├─ 本地 Web 返回 JSON（Level 1）
   └─ WiFi 上传到云端（Level 2）
      │
      ▼
   网页看板
   ├─ 实时分贝数值
   ├─ 历史曲线（Chart.js）
   ├─ 测点列表与状态
   ├─ 校园平面图噪声热力图
   └─ 分时段切换 / CSV 导出
```

**两级实现：**
- **Level 1（12月前验证）**：ESP32 开热点或连校园 WiFi，作为简易 Web 服务器返回 JSON；手机/电脑浏览器打开网页，显示当前分贝和最近数据。
- **Level 2（科技节完善）**：多测点数据上传到 Node.js 后端（PostgreSQL），网页用 Chart.js 画曲线，用校园底图 + 彩色圆点/色阶做热力图，支持分时段切换。

## 4. 软件技术栈

- **固件**：Arduino C++
- **传感器驱动**：I2S 麦克风库
- **通信**：ESP32 本地 HTTP 服务 / WiFi POST
- **后端**：Node.js + Express（`web/`，标准 npm 包，作为独立子树维护）
- **数据库**：PostgreSQL（测点、分贝读数、时段）
- **前端**：HTML + CSS + JavaScript
- **图表**：Chart.js
- **热力图**：校园平面图底图 + SVG/Canvas 彩色圆点，按距离加权简易插值
- **数据格式**：JSON，可导出 CSV

## 6. 数据格式

ESP32 返回或上传的 JSON 建议统一为：

```json
{
  "point_id": "P01",
  "location": "教学楼A走廊",
  "time": "2026-12-05 10:30:00",
  "db": 62.3,
  "period": "课间"
}
```

字段说明：

| 字段 | 类型 | 说明 |
|---|---|---|
| point_id | string | 测点编号，如 P01 |
| location | string | 测点位置描述 |
| time | string | 采集时间 |
| db | number | 平均分贝值 |
| period | string | 时段：课间 / 午休 / 放学 |

CSV 表头建议：`point_id,location,time,db,period`

## 7. 快速开始（Level 1）

1. 给 ESP32 编写程序。
2. 按接线图连接 INMP441（I2S：SCK / WS / SD / VCC / GND）。
3. 编译并刷入固件
4. 浏览器访问 ESP32 的 IP 地址，应能看到 JSON 或简易页面。
5. 按 `web/README.md` 启动后端（Node.js + PostgreSQL），浏览器访问 `http://localhost:3000`，确认能读取并显示数据；前端文件放在 `web/public`。

当前用手机 APP 验证方法，后续 ESP32 自动采集

## 8. 校准方法

低成本麦克风不能直接等同于专业声级计。校准步骤：

1. 在同一位置、同一时段，用手机分贝 APP 和 ESP32 同时测量。
2. 记录多组数据，计算 ESP32 读数与参考读数的偏移量或比例关系。
3. 后续数据统一按该关系修正。
4. 校准记录写入 `docs/校准记录.md`。

## 11. 风险与预案

| 风险 | 预案 |
|---|---|
| INMP441 未到货 | 先用手机分贝 APP 采真实数据，网页照常搭 |
| WiFi 不稳定 | 保留 SD 卡 / 串口 CSV 离线备份 |
| 网页开发慢 | 先用 Chart.js 模板 + 假数据搭 P0，再替换真实数据 |
| 热力图复杂 | 先用彩色圆点 + 简易插值，不追求专业 GIS |
| 隐私问题 | 只存分贝值、时间和测点编号，不录音 |
